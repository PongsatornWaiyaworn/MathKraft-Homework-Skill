# MathKraft Homework UI Skill

คู่มือและชุดเครื่องมือสร้างแบบฝึกหัดคณิตศาสตร์เชิงโต้ตอบ (Interactive Worksheet) ที่เป็นไฟล์ HTML เดี่ยว (Single-file HTML) ทำงานแบบ Client-side 100% ไม่ต้องพึ่งพาเซิร์ฟเวอร์ภายนอก มี KaTeX และฟอนต์ Prompt ในตัว พร้อม UI สไตล์ Retro-Neobrutalism ที่ทันสมัย สะอาด และใช้งานง่ายบนทุกอุปกรณ์

---

## 1. โครงสร้างและสถาปัตยกรรม (Architecture)

ไฟล์แบบฝึกหัดแต่ละไฟล์ถูกประกอบขึ้นจาก 3 ส่วนหลักโดย `build-hw.js`:

```
┌────────────────────────────────────────────────────────┐
│ 1. Head Shell (assets/shell/head.tpl.html)             │
│    - WOFF2 Embedded 'Prompt' Font (400, 600, 700)      │
│    - KaTeX Math Typesetting (CSS + JS bundle)          │
│    - MathKraft Design Tokens (CSS Variables)           │
│    - Engine Core (window.MK: RNG, KaTeX helper, Lab)   │
├────────────────────────────────────────────────────────┤
│ 2. Content Module (content/HW-XX_*.js)                 │
│    - window.HW = { ... }                               │
│    - Metadata, Levels (ด่านย่อย), Question generators   │
│    - Analytical solution & validation logic            │
├────────────────────────────────────────────────────────┤
│ 3. Tail Shell (assets/shell/tail.tpl.html)             │
│    - Engine UI Controller                              │
│    - Intro Screen (แผ่นปิดหน้าแบบฝึกหัด + ตราประทับ)        │
│    - Sticky Pill Bar (สลับด่านย่อย)                     │
│    - Question Renderers (Choice, Fill, Sort, Pairs...) │
│    - Grading, Summary Modal, LocalStorage state save   │
└────────────────────────────────────────────────────────┘
```

## 2. การเขียนสมการคณิตศาสตร์ (KaTeX Math Typesetting)

Engine รองรับการเขียนสมการคณิตศาสตร์แบบ LaTeX ทุกรูปแบบอย่างอัตโนมัติ:

1. **Inline Math (ในประโยค):**
   - ใช้ `$ ... $` เช่น `$a_n = 3\cdot 2^n - 6$`, `$f(x) = 2^x$`, `$x \in \mathbb{R}$`
   - หรือ `\( ... \)` เช่น `\(a_n = a_1 + (n-1)d\)`
2. **Display Math (แยกบรรทัดกึ่งกลาง):**
   - ใช้ `$$ ... $$` เช่น `$$S_n = \frac{n}{2}(a_1 + a_n)$$`
   - หรือ `\[ ... \]` เช่น `\[P(E) = \frac{n(E)}{n(S)}\]`
3. **Escaped Dollar:**
   - หากต้องการแสดงเครื่องหมายดอลลาร์ธรรมดา (ไม่ใช่สูตร) ให้ใส่ `\$` เช่น `ราคา \$100`

## 3. คำสั่ง CLI (build-hw.js)

ชุดคำสั่งหลักอยู่ที่ `scripts/build-hw.js`:

### 3.1 เริ่มต้นสร้างคอร์สใหม่ (Scaffold)
```bash
node scripts/build-hw.js --init <path-to-target-dir> --name <CourseCode>
```
คำสั่งนี้จะสร้าง:
- `course.json` พร้อมตั้งค่ารายวิชา
- โฟลเดอร์ `content/` พร้อมไฟล์โครงสร้างตั้งต้น
- โฟลเดอร์ `dist/` สำหรับเก็บไฟล์ HTML ปลายทาง

### 3.2 บิลด์เป็นไฟล์ HTML
```bash
node scripts/build-hw.js --config <path-to-course.json>
```
อ่านไฟล์ใน `content/` แล้วนำมารวมกับ `head.tpl.html` และ `tail.tpl.html` เพื่อสร้างไฟล์ HTML เดี่ยวในโฟลเดอร์ปลายทาง (`outDir`)

### 3.3 ตรวจสอบความถูกต้องของโจทย์และระบบตรวจ (Headless Multi-seed Selftest)
```bash
node scripts/build-hw.js --config <path-to-course.json> --check
```
คำสั่งนี้จะจำลองการสุ่มโจทย์ด้วย seed ต่าง ๆ (Default 120 seeds ต่อข้อ) แล้วรันระบบตรวจคำตอบอัตโนมัติ เพื่อยืนยันว่า:
- ไม่มีข้อใดคำนวณผิดพลาด (NaN, Infinity, Divide by zero)
- ตัวเลือกคำตอบถูกต้องและไม่ซ้ำกัน
- ฟังก์ชันตรวจ (Validator) ทำงานถูกต้องกับคำตอบที่ถูกต้อง

## 4. โครงสร้างไฟล์โจทย์ (`content/HW-XX_*.js`)

ไฟล์โจทย์แต่ละไฟล์จะกำหนดออบเจกต์ `window.HW` ภายใต้ IIFE:

```javascript
(function () {
  'use strict';
  const MK = window.MK, Q = MK.Q;
  const r = String.raw;

  window.HW = {
    id: 'HW-01',
    unit: 1,
    unitName: 'หน่วยที่ 1 ชื่อหน่วยการเรียนรู้',
    title: 'ชื่อบทเรียนหรือหัวข้อของแบบฝึกหัด',
    sub: 'คำอธิบายสั้น ๆ 1–2 ประโยค บอกจุดประสงค์การเรียนรู้',
    size: '8 ข้อ · 15 นาที',
    K: 2, // สัดส่วนคะแนนด้านความรู้ (Knowledge)
    P: 1, // สัดส่วนคะแนนด้านทักษะกระบวนการ (Process)
    // reviewFile: '1.1_ชื่อสื่อการสอน.html', // ลิงก์สื่อการสอน (ถ้ามี)
    levels: [
      {
        short: 'ด่าน 1',
        title: 'ด่าน 1 · วอร์มอัปความเข้าใจ',
        kind: 'K',
        points: 1,
        skill: 'ทักษะที่ฝึกในด่านนี้',
        review: 'หัวข้อ 1.1',
        desc: 'คำอธิบายด่าน',
        intro: 'คำชี้แจงก่อนเริ่มทำ',
        build(R) {
          return [ /* รายการข้อโจทย์ */ ];
        }
      }
    ]
  };
})();
```

## 5. รูปแบบข้อคำถามที่รองรับ (7 Question Types)

### 5.1 Q.choice (ปรนัย 4 ตัวเลือก)
```javascript
Q.choice({
  q: 'ค่าของ $2^4$ เท่ากับข้อใด',
  options: ['$16$', '$8$', '$32$', '$12$'],
  answer: 0, // index คำตอบที่ถูกก่อนสลับ (ระบบจะสลับให้อัตโนมัติ)
  hint: 'นำ 2 มาคูณกัน 4 ตัว',
  why: '$2^4 = 2 \\times 2 \\times 2 \\times 2 = 16$',
  verify: () => 0
})
```

### 5.2 Q.fill (เติมคำตอบตัวเลข / ข้อความ)
```javascript
Q.fill({
  q: 'กำหนดลำดับ $a_n = 3n - 1$ จงหาค่าของ $a_5$',
  fields: [{
    label: '$a_5 =$',
    answer: 14,
    unit: '',
    tol: 0,
    ph: 'พิมพ์ตัวเลข'
  }],
  hint: 'แทนค่า $n = 5$ ลงในสูตร',
  why: '$a_5 = 3(5) - 1 = 15 - 1 = 14$',
  verify: () => 14
})
```

### 5.3 Q.sort (ลากการ์ดลงกล่อง分類)
```javascript
Q.sort({
  q: 'ลากการ์ดไปวางในกลุ่มที่ถูกต้อง',
  bins: [
    { id: 'fin', label: 'ลำดับจำกัด' },
    { id: 'inf', label: 'ลำดับอนันต์' }
  ],
  items: [
    { html: '$1, 2, 3, \\dots, 20$', bin: 'fin' },
    { html: '$2, 4, 8, \\dots$', bin: 'inf' }
  ],
  hint: 'พิจารณาว่ามีพจน์สุดท้ายหรือไม่',
  why: 'ลำดับจำกัดมีจำนวนพจน์แน่นอน ลำดับอนันต์มีพจน์ไม่สิ้นสุด'
})
```

### 5.4 Q.pairs (จับคู่ 1 ต่อ 1)
```javascript
Q.pairs({
  q: 'จับคู่สมการทางซ้ายกับผลลัพธ์ทางขวา',
  left: [{ key: 'k1', html: '$2^3$' }, { key: 'k2', html: '$3^2$' }],
  chips: [{ key: 'k1', html: '$8$' }, { key: 'k2', html: '$9$' }],
  hint: 'คำนวณค่าแต่ละข้าง',
  why: '$2^3 = 8$ และ $3^2 = 9$'
})
```

### 5.5 Q.order (เรียงลำดับขั้นตอนและเลือกเหตุผล)
```javascript
Q.order({
  q: 'เรียงลำดับขั้นตอนการแก้สมการ $2x + 4 = 10$',
  steps: [
    { html: '$2x + 4 = 10$', reason: 0 },
    { html: '$2x = 6$', reason: 1 },
    { html: '$x = 3$', reason: 2 }
  ],
  reasons: [
    'สมการเริ่มต้น',
    'นำ 4 ไปลบทั้งสองข้าง',
    'หารด้วย 2 ทั้งสองข้าง'
  ],
  hint: 'ย้ายข้างค่าคงที่ก่อนแล้วค่อยหารด้วยสัมประสิทธิ์',
  why: 'ขั้นตอนการแก้สมการเชิงเส้น'
})
```

### 5.6 Q.find (จับผิดวิธีทำ: หาบรรทัดผิด + เลือกสาเหตุ + เติมคำตอบที่ถูก)
```javascript
Q.find({
  q: 'พิจารณาวิธีทำด้านล่าง แล้วระบุบรรทัดที่ผิด สาเหตุ และแก้ไขให้ถูกต้อง',
  lines: [
    'บรรทัดที่ 1: $(x - 2)^2 = 16$',
    'บรรทัดที่ 2: $x - 2 = 4$ เท่านั้น',
    'บรรทัดที่ 3: $x = 6$ ค่าเดียว'
  ],
  wrong: 1, // index บรรทัดที่ผิด
  causes: [
    'ลืมคิดคำตอบติดลบจากการถอดราก ($x - 2 = \\pm 4$)',
    'คำนวณเลขผิด'
  ],
  cause: 0,
  fixLabel: 'คำตอบที่ถูกต้องอีกค่าหนึ่งคือ',
  fix: { answer: -2, tol: 0, ph: 'พิมพ์ตัวเลข' },
  hint: 'รากที่สองของ 16 มีทั้ง +4 และ -4',
  why: '$x - 2 = -4 \\implies x = -2$'
})
```

### 5.7 Q.group (โจทย์สถานการณ์ต่อเนื่องหลายข้อย่อย)
```javascript
Q.group({
  story: '<b>สถานการณ์จำลอง</b> รายละเอียดข้อมูลโจทย์...',
  parts: [
    Q.fill({ label: 'ข้อย่อย 1', q: 'คำถามที่ 1', answer: 10, why: '...' }),
    Q.fill({ label: 'ข้อย่อย 2', q: 'คำถามที่ 2', answer: 20, why: '...' })
  ]
})
```

## 6. เครื่องมือสุ่ม (RNG Helper)

ทุกด่านจะส่งออบเจกต์ `R` เข้าไปใน `build(R)`:
- `R.int(min, max)`: สุ่มจำนวนเต็มระหว่าง `min` ถึง `max`
- `R.pick(array)`: สุ่มเลือกสมาชิก 1 ตัวจากอาร์เรย์
- `R.shuffle(array)`: สลับลำดับสมาชิกในอาร์เรย์
- `R.chance(prob)`: สุ่มคืนค่า true ตามความน่าจะเป็น `prob` (0.0 ถึง 1.0)

## 7. มาตรฐานการออกแบบ (Design Tokens & UI)

ชุดสีและสไตล์ Retro-Neobrutalism มาตรฐานเดียวกับคณิตศาสตร์เพิ่มเติม:
- **Cream Background**: `#F4F1E8`
- **Paper Surface**: `#FFFDF7`
- **Deep Navy (Line/Text/Border)**: `#16205B`
- **Accent Gold**: `#F5B335`
- **Accent Teal**: `#14A38B`
- **Accent Red / Coral**: `#F4522D`
- **Borders**: `2px solid #16205B` หรือ `2.5px solid #16205B`
- **Shadows**: `5px 5px 0 #16205B` (สไตล์ Neobrutalism หนักแน่น)
- **Typography**: Google Fonts `'Prompt'` (TH/EN) และ KaTeX สำหรับสมการ
- **Header / Brand**: `MathKraft · ครูนิพนธ์ ไวยวรณ์ · โรงเรียนนวลนรดิศวิทยาคม รัชมังคลาภิเษก`

## 8. ข้อกำหนด UI และระบบที่เป็นมาตรฐานเดียวกัน (Standardization Rules)

ทุกแบบฝึกหัดที่สร้างขึ้นด้วย Skill นี้ ต้องปฏิบัติตามมาตรฐาน UI เดียวกับวิชาคณิตเพิ่มเติมอย่างเคร่งครัด:

1. **โครงสร้างหน้าแรก (Gate / Login):**
   - **Hero Card**: โลโก้ MathKraft (`window.MK_LOGO`), แท็กวิชาและรหัส, ชื่อแบบฝึกหัด, ข้อความแบรนด์, ป้ายแสดงข้อมูล (ชิ้นที่, เวลา, คะแนน K/P)
   - **Card 1 (กรอกข้อมูลนักเรียน)**: ช่องกรอกข้อมูล 3 ช่องในกริด (`.formgrid`):
     - `ชื่อ-สกุล` (`#f-name`)
     - `ชั้น` (`#f-cls`)
     - `เลขที่` (`#f-no`)
     - ปุ่มยืนยัน: `<button type="button" class="btn pri" id="start">เริ่มทำแบบฝึก →</button>`
   - **Card 2 (ด่านในแบบฝึกนี้)**: รายการด่าน/หัวข้อย่อยพร้อมคะแนน
   - **Card 3 (กติกาสั้น ๆ)**: กติกา 4 ข้อชัดเจน (ทำได้ 2 ครั้ง นับครั้งที่ดีกว่า, คะแนนถูกครั้งแรกเต็ม ครั้งที่สองได้ครึ่ง, การผูกรหัสยืนยันผล, และการส่งคำตอบ)

2. **หน้าทำแบบฝึกหัด (Work View):**
   - **ไม่มีแถบข้อมูลนักเรียน (No Student Bar)**: ไม่มีแถบแสดงชื่อ ชั้น เลขที่ หรือปุ่มเปลี่ยนผู้ทำในหน้าทำแบบฝึกหัด
   - **แถบ Pills ด้านบน**: แสดงสถานะแต่ละด่านชัดเจน

3. **หน้าสรุปผล (Summary Modal):**
   - การ์ดคะแนนสรุปสไตล์ Neobrutalism พร้อมวงแหวนเปอร์เซ็นต์
   - ตารางแจกแจงคะแนนรายด่าน
   - รหัสยืนยันสำหรับส่งครู: `<span class="code" id="s-code">...</span>`
   - ปุ่มหลักมีเฉพาะ:
     - `📋 คัดลอกผลสรุป`
     - `ทำครั้งที่ 2 (ตัวเลขชุดใหม่) →` (ถ้ายังทำไม่ครบ 2 ครั้ง)

4. **ข้อห้ามเด็ดขาด (Prohibited Elements):**
   - **ห้ามมีแถบข้อมูลนักเรียนหรือปุ่มเปลี่ยนผู้ทำระหว่างทำแบบฝึกหัด**
   - **ห้ามมีแถบนำทาง (Navbar / Breadcrumb) ด้านบน**: เช่น ลิงก์ย้อนกลับ `🏠 หน้าหลัก` หรือ path ภาษาอังกฤษ/ไทย
